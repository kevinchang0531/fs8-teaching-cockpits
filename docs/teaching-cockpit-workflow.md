# FS8 教學駕駛艙工作流程

來源教材：`8 FS8 FSW PRESELECTION介紹與操作說明.pdf`  
本版日期：2026-07-25

## 第 1 階段：讀取教材與建立教學藍圖

1. 確認原始教材檔、版本、使用對象與課程目的。
2. **完整讀取教材內容**，並以 NotebookLM 與人工檢核整理主題、關鍵名詞、程序節點、常見誤解與可測量的學習目標。
3. 產出教材地圖與教學重點清單，作為後續簡報、資訊圖表、互動視覺化與評量的共同依據。

輸出：教材摘要、主題分段、教學目標、來源與日期紀錄。

## 第 2 階段：教學設計

1. 每個教學重點對應一組簡報輪播、互動視覺化與資訊圖表。
2. 形成性評量每個重點設計 **1–3 題**；本階段以布魯姆認知層次的「記憶、理解」為主。
3. 教師模式顯示教學提示；學生模式只保留自學所需資訊。

## 第 3 階段：教材產製與最佳化

1. 用 NotebookLM 產出黑板粉筆風格的教學簡報與資訊圖表；無法下載或需補足的素材，維持相同視覺規格後補製。
2. 簡報下載為單張圖片；網站使用版統一轉為 1920×1080 JPG。
3. 原始 PDF、原始 PNG 與高解析素材保留在工作區，不放入 GitHub Pages 發布包。

## 第 4 階段：駕駛艙製作

1. 以靜態網站整合每個教學重點的輪播、視覺化、評量與資訊圖表。
2. 提供教師／學生模式、抽籤、計時器與畫筆工具；畫筆與色彩工具置於左側。
3. 以平板為主要情境完成響應式設計：觸控按鈕至少 44px、雙欄教材區在中型螢幕可讀、工具面板改為底部橫向排列且預留內容空間。

## 第 5 階段：影片整合

1. 影片不自動上傳。
2. 目前顯示教學影片預留圖；使用者提供 YouTube 網址後，才更新為嵌入式播放器。
3. 建議將影片設為 YouTube「不公開」，再以嵌入連結整合，以避免 GitHub Pages 的檔案與流量限制。

## 第 6 階段：資料功能（延後）

目前不加入資料庫、登入、作答紀錄或成績追蹤。日後若需要跨裝置保存、教師檢視進度或班級分析，再另行決定資料欄位、權限與隱私設計。

## 第 7 階段：GitHub 發布與驗證

1. 發布包只包含 HTML、CSS、JavaScript 與最佳化 JPG。
2. 不納入影片、原始 PDF、PNG 原檔或開發相依檔案。
3. 每次部署後驗證入口頁、駕駛艙頁、腳本與代表性圖片皆可經由 GitHub Pages 載入；驗證時使用版本參數避開瀏覽器快取。
